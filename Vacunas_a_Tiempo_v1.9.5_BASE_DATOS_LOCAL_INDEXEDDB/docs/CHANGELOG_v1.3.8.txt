- Se reparó la inicialización de Tesseract.js usando rutas explícitas para worker, núcleo e idioma español.

PDF
- Ahora admite archivos PDF además de JPG, PNG y WEBP.
- Muestra el número total de páginas.
- Permite navegar entre páginas y ejecutar OCR sobre la página visible.
- Renderiza las páginas a mayor resolución antes del reconocimiento.

SEGURIDAD

- El programa no guarda automáticamente la imagen o el PDF.

NOTA
